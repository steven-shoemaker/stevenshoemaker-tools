# SF font subset (woff2)

Latin-subset builds of SF Pro Text, Display, Rounded, and SF Mono for tools apps.

Regenerate from your local Apple fonts folder:

```bash
npm run fonts:sync
```

Default source: `~/Documents/apple-san-francisco-pro-fonts`  
Override: `SF_FONTS_SRC=/path/to/fonts npm run fonts:sync`

**License:** Apple’s San Francisco fonts are subject to Apple’s license. Confirm you’re allowed to host/redistribute before a public deploy.
